# 실제 게시판 설정 순서

이 프로젝트는 Cloudflare Pages Functions + D1을 사용합니다.

## 반드시 설정할 것

1. Cloudflare에서 D1 데이터베이스 생성
2. D1 콘솔에서 `schema.sql` 실행
3. 샘플 글이 필요하면 `seed.sql` 실행
4. Pages 프로젝트 Settings > Bindings에서 D1 binding 추가
   - Variable name: `DB`
   - 생성한 D1 데이터베이스 선택
5. Pages 프로젝트 Settings > Variables에서 환경변수 추가
   - `ADMIN_EMAIL` = 관리자 이메일 주소
6. Cloudflare Zero Trust Access에서 두 경로 보호
   - `ryeo-archive.pages.dev/admin/*`
   - `ryeo-archive.pages.dev/api/admin/*`
   - Allow 정책에는 관리자 이메일 하나만 등록
   - 로그인 방식은 One-time PIN(OTP)
7. GitHub에 이 폴더 전체 업로드 후 재배포

## 관리자 주소
`https://ryeo-archive.pages.dev/admin/`

## 일반 이용자
공개 처리한 글만 慮 내부망 사건 기록에 나타납니다.


## v2 고정 선택 항목
- 괴이 유형은 관리자 화면에서 한글 체크박스로 복수 선택
- 저장 및 공개 화면에서는 `現象 / 個體 / 物件 / 傳染 / 記錄 / 未分類` 한자로 표시
- `未分類`는 다른 유형과 동시에 선택되지 않음
- 위험 분류는 `평가 불가 / 접근 제한 / 기록 오염 / 인명 위험` 드롭다운
- 진행 상태는 `관찰 중 / 분석 중 / 회수 대기 / 격리 유지 / 회수 완료 / 열람 금지 / 회수 기록 없음` 드롭다운
- 공개 사건 목록에서 위험·상태에 따라 색상이 자동 지정됨


## 연도별 기록 색인 v3
- 관리자와 내부 기록망 사건 기록 화면에 1912~2026 연도 필터 추가
- 1912년 이전 기록은 열람 금지 처리하고 총 1,473건과 상태별 통계만 표시
- 1912~2026 색인 총 3,195건, 전체 색인 4,668건
- 연도별 숫자는 실제 사건 데이터가 아니라 세계 각지의 미해결 사건·실종·항공·해상·기록 미스터리가 시대별로 증가했다는 설정을 반영한 픽션용 색인 수치
- 실제 게시글은 D1 데이터베이스에 등록된 기록만 클릭 가능
- 데이터베이스 스키마 변경 없음


## v6 현황 자동 집계
- 삼직 보고의 활성 보고·미해명·격리 유지 숫자는 공개 기록 API 결과를 기준으로 자동 계산됩니다.
- 활성 보고: 관찰 중 + 분석 중 + 회수 대기
- 미해명: 회수 기록 없음
- 격리 유지: 격리 유지
- 비공개 기록은 집계에서 제외됩니다.

## v7 삼직 보고 D1 실시간 집계
- `/api/records/stats`가 D1의 공개 기록(`is_published = 1`)을 직접 집계합니다.
- 활성 보고: 관찰 중 + 분석 중 + 회수 대기
- 미해명: 회수 기록 없음
- 격리 유지: 격리 유지
- 목록 표시 제한과 무관하게 전체 공개 기록을 정확히 셉니다.
- 새 기록 저장 또는 상태 변경 후 사이트를 새로고침하면 즉시 반영됩니다.
