# RYE Site V14 — Full Responsive Mobile Pass

## 변경 내용
- 보안 접속 전환 패널을 모든 모바일에서 화면 정중앙(50% / 50%)에 고정
- 위치는 `%`, 화면 크기는 `dvw/dvh`, 글자/간격은 `clamp()` 기반으로 유동화
- iPhone safe-area 반영
- 360 / 375 / 390 / 412 / 430px 계열 대응
- 좁은 휴대폰에서는 카드/필터 자동 1열 전환
- 가로모드 및 낮은 화면 높이 별도 대응
- 기록 모달 모바일 화면 이탈 방지
- 게시판 표는 내용이 찌그러지지 않도록 가로 스크롤 허용
- 검색/버튼/숨겨진 표식의 터치 영역 유지
- 데스크톱 레이아웃은 기존 동작 유지

## 핵심 원칙
중앙 위치:
`left: 50%; top: 50%; transform: translate(-50%, -50%);`

반응형 폭:
`min(92dvw, safe-area를 제외한 가용 폭, 최대 폭)`

고정 px은 테두리/최소 안전 여백/터치 최소치처럼 필요한 곳에만 사용.
