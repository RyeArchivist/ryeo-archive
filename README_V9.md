# v9 — 삼직 보고 실시간 D1 집계 확정판

## 수정 내용
- `/api/records`가 사건 목록과 삼직 보고 통계를 한 번에 반환합니다.
- 별도 통계 API 라우팅이 실패해도 12/8/3 같은 고정 숫자가 남지 않습니다.
- 공개 기록(`is_published = 1`)만 집계합니다.
- 활성 보고: 관찰 중 + 분석 중 + 회수 대기
- 미해명: 회수 기록 없음
- 격리 유지: 격리 유지
- API 연결 실패 시 고정 숫자 대신 `연결 오류`를 표시합니다.
- 사건기록은 D1 단계에서도 연도/번호 내림차순으로 정렬됩니다.

## 배포
압축을 풀어 GitHub 저장소의 기존 파일을 전부 덮어쓴 뒤 Cloudflare Pages 새 배포가 끝날 때까지 기다립니다.
D1 SQL은 다시 실행하지 않습니다.
배포 후 사이트에서 Ctrl+F5를 누릅니다.
